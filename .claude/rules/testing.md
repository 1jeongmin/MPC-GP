# 검증 테스트 룰

## 원칙

테스트는 "코드가 돌아가는지"가 아니라 **"물리가 맞는지"**를 본다.
아래 게이트 중 하나라도 실패하면 다음 Phase로 넘어가지 말고 원인을 먼저 보고하라.
실패한 테스트를 완화하거나 허용오차를 늘려서 통과시키지 마라.

## 게이트 1 — 정상상태 요레이트 (최우선)

sedan config, `vx = 15 m/s`, `kappa = 0`, `x0 = 0`, `delta = 0.02 rad` 스텝을 주고
충분히 긴 시간 적분한 뒤:

정상상태 `gamma`가 `steady_state_yaw_rate(cfg, 15, 0.02)`와 **1% 이내** 일치.

불일치 = A/B 행렬의 부호나 `Cf`/`Cr` 정의가 틀린 것이다.
**여기서 멈추고 보고하라. MPC 구현으로 넘어가지 마라.**

## 게이트 2 — 언더/오버/뉴트럴 스티어

`Cf, Cr, a, b`를 조정해 세 경우를 만들고 `K_us` 부호와 정상상태 요레이트의
대소관계가 이론과 맞는지 확인한다.

## 게이트 2b — 고유값·임계속도 (자주 틀리는 지점)

**4x4 전체 `A`에 "고유값 실수부가 모두 음수" 검사를 걸지 마라. 반드시 실패한다.**
`A`는 블록 하삼각이고 오차 기구학에서 원점 고유값이 2개 나온다(정상).

올바른 검사:
- `A_lat = A[0:2, 0:2]`의 고유값 2개 모두 실수부가 음수 (sedan, `vx = 15`)
- `A[2:4, 2:4]`(오차 기구학 블록)의 고유값 2개가 모두 0인지 확인 (구조 검증).
  이 블록은 `[[0, 0], [vx, 0]]`이므로 0의 중근이 나오는 것이 정상이다.
- 위 두 집합의 합이 `eig(A)` 전체와 일치하는지 (블록 하삼각 구조 검증)
- `det(A_lat) > 0 ⟺ L + K_us*vx^2 > 0` 이 수치적으로 성립하는지
- 오버스티어 config를 만들어 `v_crit` 근처에서 안정 → 불안정 전환이 일어나는지

`L + K_us*vx^2`는 `steady_state_yaw_rate`의 분모와 같은 식이다.
게이트 1과 이 게이트가 동시에 통과해야 부호 규약이 맞는 것이다.

## 게이트 3 — numpy ↔ CasADi 일치

같은 입력에 대해 두 경로의 `xdot` 차이가 **1e-10 이내**.

## 게이트 4 — 특이점 방어

`vx_range` 하한을 0 이하로 설정하면 config 유효성 검사가 예외를 던지는지.
런타임에 `v_x`가 하한 미만이 되면 예외를 던지는지.

## 게이트 5 — noise floor 정량화

RK4(`dt_ctrl`)와 고정밀 적분기의 궤적 차이를 **숫자로 출력**한다.
이 값은 이후 잔차 해석의 기준선이므로 테스트가 값을 삼키지 말고 리포트하라.

## 게이트 6 — MPC 정합성

- 초기오차 0, `kappa = 0` → `delta`가 거의 0
- 초기 `e_y = 0.5 m` → 오차를 줄이는 방향의 `delta`
- 모든 제약이 수치 허용오차 내에서 만족
- IPOPT 수렴 실패 시 처리 경로가 실제로 동작하는지 (실패를 인위적으로 유발해 확인)

## 게이트 7 — GP

- 잔차가 0인 데이터로 학습하면 GP 평균이 ~0이고 분산이 사전분산 수준인지
- 학습 데이터에서 멀어질수록 사후 표준편차가 **단조적으로 증가**하는지
  (이것이 실패하면 논문의 핵심 주장이 코드에서 성립하지 않는 것이다)
- GPyTorch 예측과 CasADi 변환본 예측이 일치하는지
- 표준화 통계를 저장·재적용했을 때 예측이 동일한지

## 게이트 8 — 참조 경로

- 일정곡률 구간에서 복원된 (x,y)가 반지름 `1/kappa`인 원호와 일치
- 프리뷰 배열 길이가 항상 `N`이고, 경로 끝에서 마지막 값이 유지되는지

## 실행

빠른 게이트(1~4, 8)는 매 커밋. 무거운 게이트(6, 7)는 별도 마커로 분리한다.
