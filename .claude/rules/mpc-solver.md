# MPC 정식화·솔버 룰

## 정식화 (multiple shooting + IPOPT)

- 결정변수: `X (4 x (N+1))`, `U (1 x N)`
- 파라미터 `P`: `[x0(4), vx_preview(N), kappa_preview(N), u_prev(1)]`
  - **GP 케이스는 여기에 GP 블록을 이어 붙인다** (아래 「GP 결합 시」 참조).
    명목 케이스와 GP 케이스는 `P` 레이아웃이 다르다. 레이아웃 정의는 한 곳에
    두고(예: `P_layout` 헬퍼) 인덱스를 손으로 세지 마라.
- 동역학 등식 제약: `X[:,k+1] = rk4_step(...)`, 각 스텝의 `vx`, `kappa`는 `P`에서 꺼낸다
  (GP 케이스에서는 여기에 GP 보정항이 더해진다)

비용:
```
sum_k [ W_ey*e_y^2 + W_epsi*e_psi^2
        + W_vy*v_y^2 + W_gamma*(gamma - vx*kappa)^2   # gamma 만 참조 상대
        + R_delta*delta^2 + R_ddelta*(delta_k - delta_{k-1})^2 ]
+ 종단항 (e_y, e_psi)
```

제약:
```
|delta| <= delta_max
|delta_k - delta_{k-1}| <= delta_rate_max * dt      # k=0 에는 P의 u_prev 사용
```
상태 제약은 지금 넣지 않는다. 추가하려면 먼저 물어라.

**모든 가중치는 `configs/mpc/*.yaml`에서 읽는다. 하드코딩 금지.**

## 참조 상태·피드포워드를 별도로 계산하지 마라 — `gamma` 한 채널만 예외

`x_ref`, `u_ref`를 명시적으로 만들지 않는다. `kappa` 프리뷰가 지평에 채워지면
MPC가 필요한 요레이트를 스스로 만든다. 비용은 `e_y`, `e_psi`를 0으로 보내고
`delta`와 그 변화율을 벌주는 것으로 충분하다.

Mehrez 워크숍의 multiple shooting 골격을 따르되 **이 점이 다르다.**
워크숍 코드를 그대로 옮기면서 `u_ref` 항을 되살리지 마라.

### 예외 — `W_gamma` 는 `(gamma - vx*kappa)^2` (2026-07-27 사용자 확정)

위 원칙에는 구멍이 있었다. 곡선에서 **완벽추종에 필요한 값이 0 이 아닌** 양을
절대값으로 벌주면, 목적함수가 동역학 등식제약과 반대 방향을 지시한다.
`gamma` 가 그 대표 사례다 (`kappa=0.02, vx=14.14` 에서 필요 `gamma_ss = 0.283 rad/s`).

**측정 근거** (ay4, `plant=linear` 로 모델오차를 0 으로 만든 뒤):
`W_gamma*gamma^2` 는 완벽추종 시 잔여 스테이지 비용의 65.8% 를 차지했고,
일정곡률 정상편차 `e_y` 를 3.35e-3 m 만들었다 (이 항만 끄면 6.87e-4 로 감소).

**이 예외가 `gamma` 에만 허용되는 이유:**

| 채널 | 참조 | 비선형 플랜트 대비 참조 오차 | 판정 |
|---|---|---|---|
| `gamma` | `vx*kappa` — **순수 기구학** | **0.02%** | 예외 허용 |
| `delta` | `kappa*(L + K_us*vx^2)` — `Cf,Cr,m` 의존 | +2.74% | 불허 |
| `v_y` | 선형 정상상태해 — `Cf,Cr,m,Iz` 의존 | **−206.6%** | 불허 |

`gamma_ref = vx*kappa` 는 오차 기구학 `e_psi_dot = gamma - vx*kappa` 그 자체이므로
**차량 파라미터가 하나도 들어가지 않는다.** 따라서 선형모델의 오차를 목적함수에
두 번째 경로로 들여오지 않는다 (CLAUDE.md 「잔차의 출처를 타이어 비선형성 하나로
통제」 유지).

`delta`, `v_y` 의 참조는 GP 가 학습하기로 되어 있는 바로 그 선형모델에서 나온다.
이들을 참조 상대로 바꾸면 실험 설계가 깨진다. **확장하지 마라.**

구현: `p_vx[k] * p_kappa[k]` — 이미 `P` 에 있는 프리뷰를 쓰므로 새 파라미터도
NLP 재빌드도 없다.

## 크기 페널티를 쓸 수 있는 양 — 판정 기준 (2026-07-27 확정)

정상선회에서 차량은 힘·모멘트 평형에 있다. 경로 `(kappa, vx)` 가 평형점을 유일하게
결정하므로 `gamma`, `v_y`, `delta` 는 **경로가 정하는 값이지 컨트롤러가 고를 값이 아니다.**
물리적으로 0 이 정답인 양은 두 종류뿐이다:

1. **추종오차** `e_y`, `e_psi` — "경로 위에 있다"의 정의상 0
2. **시간미분** — "정상상태"의 정의상 0

이 둘 중 어느 쪽도 아닌 양에 `x^2` 를 걸면, 추종 문제에 **레귤레이션 목적(상태를
원점으로)** 을 섞는 것이다. 원점이 목표가 아니므로 이건 튜닝 문제가 아니라 범주 오류다.

따라서 어떤 항의 0 이 틀렸다고 판명되면 대응은 두 가지뿐이다:

| 상황 | 대응 | 적용 사례 |
|---|---|---|
| 믿을 만한 참조가 있다 | 참조 상대로 바꾼다 | `gamma` (참조 오차 0.02%) |
| 믿을 만한 참조가 없다 | **항을 없앤다** | `v_y` (−206.6%), `delta` (+2.74%) |

**가중치만 줄이는 것은 답이 아니다.** 틀린 0 을 유지한 채 "덜 틀리게" 하는 것일 뿐,
편차를 없애지 못하고 근거도 없다.

`W_vy = 0`, `R_delta = 0` 으로 확정했다. 이 결정으로 물리적 안전장치가 사라지지
않는다는 것을 세 시나리오에서 확인했다:

| 시나리오 | RMS `e_y` | max\|α_f\| | max\|α_r\| | rate 포화 |
|---|---|---|---|---|
| ay4 | 1.068e-2 → **8.580e-3** | 3.680° → **3.424°** | 3.134° → **3.089°** | 18.0% → **13.5%** |
| ay6 | 2.945e-2 → **2.473e-2** | 6.858° → **6.413°** | 5.949° → **5.755°** | 23.3% → **16.2%** |
| dlc | 1.092e-2 → **9.232e-3** | 4.243° → **4.143°** | 2.979° → 3.077° | 55.7% → **48.8%** |

추종·전륜슬립·조향포화가 **전부 동시에** 좋아진다. 애초에 이 항들이 안전성이나
평활도를 사주고 있지 않았다는 뜻이다. 각 물리적 관심사는 이미 옳은 구조가 맡고 있다:

- 전륜 포화 → 하드제약 `|delta| <= delta_max`
- 횡방향 안정성 → `A_lat` Hurwitz (언더스티어 `K_us>0` 이면 전 `vx` 보장, vehicle-model.md)
- 액추에이터 평활 → `R_ddelta` (변화율 항이라 정상상태에서 0, 구조가 옳다)

`W_vy`, `R_delta` 를 "작은 정규화"라며 되살리지 마라. 되살리려면 위 표를 반증하라.

## 표기 충돌 — 반드시 지킬 것

MPC 비용 가중치와 칼만필터 잡음 공분산은 **둘 다 관례적으로 Q, R**이라 불린다.
이 저장소에서는 절대 같은 이름을 쓰지 않는다.

| 대상 | 코드 이름 |
|---|---|
| MPC 상태·입력 가중치 | `W_x`, `W_u`, `W_du` (또는 `Q_ey` 등 명시적 이름) |
| KF 프로세스·측정 잡음 공분산 | `Q_kf`, `R_kf` |

## GP 결합 시

- GP 잔차 평균은 비선형 커널 함수다. 명목 모델이 선형이어도 **결합 모델은
  비선형이 되므로 NMPC**다. QP 솔버(osqp, qpOASES 등)로 전환하려는 시도를 하지 마라.
  전환 가능성은 GP가 없는 명목 케이스에 한해서만 논의 대상이다.
- **결합은 이산(discrete) 형태로 확정되어 있다.** GP 잔차는 상태 차이 단위이므로
  연속 우변에 더하면 `dt_ctrl`배 틀린다. 상세는 `gp-residual.md` 「결합 형태」 참조.

- **GP 평균은 현재 작동점에서 한 번 평가해 지평 상수로 주입한다 (Phase 7 진단 확정).**
  각 지평 스텝의 예측 상태 `z_k` 에서 평가하는 상태의존 결합은 **금지** — mean-only
  MPC 가 GP 부정확 영역을 최적화에서 악용해 불안정해진다(격자 완벽적합에도 -74%).

```
mu_hat = mu_GP(z_now),  z_now = [v_y, gamma, delta_prev]   # solve당 1회, 지평 상수
X[:,k+1] = rk4_step(f_nom, X[:,k], U[k], (vx_k, kappa_k), dt_ctrl) + B_d @ mu_hat
B_d = 4x2, 상단 2x2 단위행렬        # v_y, gamma 행에만 주입
```

- `e_psi`, `e_y` 행에는 **더하지 않는다.** 이 두 행은 순수 기구학이다.
- GP 평가는 solve당 **1회**(작동점)다. 따라서 `M` 은 solve time 에 무관하고 적합
  품질만 결정한다. mu_hat 은 CasADi 파라미터(2)로 주입 -> NLP 재빌드 없음.
- GP 가 KF 를 이기는 이유: 둘 다 지평 상수 외란이지만 GP 는 상태->외란을 직접 학습해
  현재 상태에서 즉시 정확하고, KF 는 시간축 필터라 지연된다 (모델보정자 vs 상태추정기).
- 왜 상태의존이 아닌가: 상태의존 결합 + mean-only 는 최적화기가 GP 부정확 영역을
  악용한다. 이를 쓰려면 caution(분산 페널티)이 필요한데 이번 스코프 밖이다.
- 상태의존 결합의 GP 평가는 RK4 밖 solve당 `N`회였을 것이나, 상수 결합에서는 무의미.

## NLP 구조 재생성 금지

온라인 GP에서 dictionary가 갱신되어도 **NLP를 매 스텝 다시 빌드하지 마라.**
inducing point 개수 `M`을 고정하고, `Z`, `alpha`, 하이퍼파라미터를 CasADi
**파라미터로 주입**해 `nlpsol` 객체를 재사용한다. (제안 — 구조 고정이 목적이며,
실제 solve time 이득은 프로파일링으로 확인할 것)

## 솔버 운영

- **warm start**: 이전 해를 저장해 다음 스텝 초기추정으로 재사용한다.
- **solve time**: 매 호출마다 기록해 반환한다. Part 2의 핵심 지표다.
  IPOPT iteration 수와 수렴 플래그도 함께 반환한다.
- **수렴 실패 처리**: 조용히 넘어가지 마라. 실패를 로그에 기록하고,
  fallback(이전 해의 shift 적용) 여부를 명시적으로 구현한 뒤 그 사실을 보고한다.
  실패율은 결과 리포트에 반드시 포함한다.
- IPOPT 옵션(`max_iter`, `tol`, `print_level`)은 config에서 읽는다.
  케이스 간 비교 시 옵션을 동일하게 유지하라. 다르면 solve time 비교가 무의미하다.
